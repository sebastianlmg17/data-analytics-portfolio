# Banking Transaction Analysis

## Overview

This project applies SQL to a realistic retail banking dataset to answer business questions about customers, accounts, transactions, branches, and merchants.

The project will grow progressively as new SQL concepts are learned. The first analyses will use only concepts already practiced, with more advanced queries added later.

## Current SQL skills applied

- SELECT
- WHERE
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- INNER JOIN
- GROUP BY
- HAVING
- ORDER BY
- DISTINCT

## Project structure

- `data/` — dataset and database information
- `queries/` — SQL analyses organized by business question
- `results/` — relevant outputs and findings

## Objective

Use SQL to explore banking activity and translate business questions into reproducible queries and insights.
