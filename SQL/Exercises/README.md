# SQL Exercises

This folder contains the SQL exercises completed during my learning process.

The exercises use the MySQL Sakila sample database and are organized progressively by SQL concept, including basic queries, filtering, JOINs, GROUP BY, HAVING, and additional concepts as they are learned.

These exercises document my learning progression and are separate from the end-to-end SQL projects in the main SQL portfolio.

## Current practice areas

- Basic Queries
- Filtering
- JOINs
- GROUP BY
- HAVING

Future concepts will be added as the learning process continues.
