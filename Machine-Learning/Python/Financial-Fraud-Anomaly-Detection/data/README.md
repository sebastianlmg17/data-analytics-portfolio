# Dataset availability

The raw financial-transactions CSV is **not included** in the public repository. The provided notebook reads `fraud (1).csv` from the execution working directory; the academic instructions call the dataset `fraud.csv`.

The notebook's saved outputs describe 10,492 rows, with 10,000 legitimate and 492 fraudulent records. Columns include numeric `V1`–`V28`, `Amount` and binary label `Class`.

**Source, license, sampling and checksum are unverified.** No redistribution rights are asserted. Obtain the dataset through its authorized provider before attempting full reproduction. Do not substitute a differently sampled public credit-card dataset and claim identical metrics.

The original CSV should not be committed until its source, permitted use and any privacy implications have been checked.
