# Machine Learning with Python

This section is prepared for standalone Machine Learning projects developed programmatically in Python. No standalone Python ML projects have been added here yet.

Future projects should document their dataset, business objective, preprocessing, reproducible environment, validation strategy and results. Reimplement an existing Dataiku project only when the Python version demonstrates a clear additional contribution, such as a reproducible pipeline or a different validation strategy.

Python fundamentals and Data Wrangling remain in the [portfolio Python section](../../Python/). Supporting Python recipes used inside Dataiku projects remain with their original workflows in [Dataiku](../Dataiku/).
