# Random Forest

Random Forest was used as the bagging-based tree ensemble.

## Configuration

- Number of trees: 100
- Maximum depth: 6
- Minimum samples per leaf: 1
- Feature sampling strategy: Square root

## Test Results

- ROC AUC: **0.9592**
- Accuracy: **0.8991**
- Precision: **0.8174**
- Recall: **0.8564**
- F1-score: **0.8365**

## Confusion Matrix

- TP: 2,588
- FN: 434
- FP: 578
- TN: 6,430
