# Boston Housing — Regularized Regression

## Overview

Compare linear regression and regularization on 506 Boston Housing observations.

## Objective

Predict `MEDV` and assess whether feature reduction improves a simpler model.

## Tools

Dataiku DSS.

## Methodology at a glance

Review data quality, use a common 399/107 train/test partition, and compare OLS, Ridge, Lasso and Lasso feature reduction.

## Results and current limits

Reduced Lasso (alpha **0.1**, 11 predictors): R² **0.7244**, MAE **3.395**, MSE **18.949**. Completed. The source dataset and executable Dataiku export are not published here.
