# Feature Engineering

## Overview

Feature engineering was performed in Dataiku after the initial data cleaning to convert categorical information into a format suitable for Machine Learning models.

## Target Encoding

The target variable `Attrition` was converted from categorical values to a binary representation:

```text
Yes → 1
No  → 0
```

This allowed the problem to be treated as a binary classification task.

## One-Hot Encoding

One-Hot Encoding was applied to the following categorical variables:

* `Gender`
* `BusinessTravel`
* `Department`
* `EducationField`
* `JobRole`
* `MaritalStatus`
* `OverTime`

After encoding, the original categorical columns were removed and the generated binary features were retained.

Empty values generated by the encoding process were treated as `0`.

## Numerical Variables

The numerical variables were reviewed individually. Scaling was considered for variables such as:

* `DailyRate`
* `HourlyRate`
* `MonthlyIncome`
* `MonthlyRate`

Scaling was ultimately not applied because the main initial model was a **Decision Tree**, which does not require feature scaling.

## Result

The resulting feature set contained numerical variables together with the encoded categorical features and the binary target. This prepared dataset was then used for the train/test split and subsequent Machine Learning experiments.
