# Images

## Overview

This folder contains the visual documentation of the project.

The images provide a complete overview of the machine learning workflow, from data preparation to model evaluation and final model selection.

These screenshots complement the project documentation and illustrate the implementation carried out in Dataiku DSS.

---

## Images Included

### Dataiku Workflow

Displays the complete Dataiku workflow developed for this project, including data preparation, feature engineering, train/test split, sampling techniques and machine learning models.

---

### Train/Test Split

Shows the 80/20 Train/Test Split configuration used before model training.

---

### Original Model Metrics

Presents the evaluation metrics obtained by the Random Forest model trained using the original dataset.

---

### Oversampling Metrics

Shows the evaluation results of the model trained using the Oversampling dataset.

---

### Undersampling Metrics

Shows the evaluation results of the model trained using the Undersampling dataset.

---

### Model Comparison

Compares the performance of the three training strategies evaluated during the project.

---

### Confusion Matrix

Displays the confusion matrix of the selected Random Forest model, providing insight into the model's classification performance.

---

### Feature Importance

Illustrates the most influential variables used by the Random Forest model to make predictions.

---

## Purpose

These visualizations provide supporting evidence for the decisions made throughout the project and help demonstrate the complete end-to-end machine learning workflow implemented in Dataiku.
