## Python Fundamentals

The fundamentals section currently covers variables and operators, core data structures, indexing and slicing, conditional logic, loops, `range()`, and accumulator patterns.

It also includes practical work with lists, tuples, sets and dictionaries, including nested structures and common methods such as `append()`, `remove()`, `pop()`, `sort()` and `reverse()`.

[Explore Python Fundamentals](./01-python-fundamentals/)

## Data Analytics Focus

The objective is not only to learn Python syntax, but to build the programming foundation required to work with real-world data. As the learning journey progresses, the repository will document how Python is applied to data cleaning, transformation, analysis, visualization and machine learning.

## Learning Methodology

The repository is updated progressively as concepts are learned, reviewed and demonstrated in practice. Course units are used as a learning reference, but the GitHub structure prioritizes **professional skills and Data Analytics relevance** rather than the original course sequence.
