# Practical Exercises

This section will contain selected exercises that demonstrate practical understanding of the Python fundamentals covered so far.

The objective is **not** to collect every exercise from the course, but to keep representative problems that demonstrate the ability to apply the concepts independently.

## Exercises Covered So Far

### 01 — List Manipulation
Practice with `append()`, `remove()` and `pop()`, including understanding the value returned by `pop()`.

### 02 — Indexing and Slicing
Accessing individual elements and extracting portions of a list using indexes and slices.

### 03 — Nested Data Access
Navigating dictionaries and lists to access values inside structured data.

### 04 — Conditional Logic
Building `if / elif / else` logic using comparisons and boolean operators.

### 05 — Filtering with a Loop
Using `for` and `if` together to process only values that satisfy a condition.

### 06 — Accumulating Values
Using an accumulator inside a `for` loop to calculate a total.

### 07 — Loop + Condition + Accumulator
Combining iteration, filtering and accumulation to calculate a result from selected values.

## Demonstrated Patterns

- Manipulating collections
- Accessing structured data
- Filtering values
- Applying logical conditions
- Iterating through collections
- Building calculated results with accumulators

## Practice Status

These concepts are **not considered mastered simply because they have been documented**. They will continue to be practiced through increasingly varied exercises until they can be applied consistently without assistance.

New representative exercises will be added as the learning journey progresses.
