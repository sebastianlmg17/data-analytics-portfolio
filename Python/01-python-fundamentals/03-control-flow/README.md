# Control Flow

This section documents the control-flow concepts practiced so far.

## Conditional Statements

- `if`
- `elif`
- `else`
- Comparison-based conditions
- Multiple conditions with `and` and `or`
- Boolean negation with `not`
- Nested conditions

## Loops

### `for`

Used to iterate through collections and process each element.

### `while`

Used to repeat a block while a condition remains true.

### `range()`

Used with `for` to generate a sequence of numbers. The stop value is not included.

## Combining Control Flow

Practiced patterns include:

- Looping through a list and applying a condition
- Filtering values using `if`
- Calculating values with an accumulator
- Combining logical conditions with loops

## Accumulators

A variable can be initialized before a loop and updated on each iteration to build a result, such as a sum.

This pattern is an important foundation for later data-processing operations.

## Data Analytics Relevance

Control flow allows data-processing logic to be expressed programmatically: filtering records, applying business rules, validating values and calculating derived results.
